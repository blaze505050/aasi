# Anthropic Scientific & Engineering Skills

## 1. Scientific Research Method
- **Hypothesis-Driven Inquiry**: Every inquiry begins with an explicit question, testable predictions, and falsification criteria.
- **Epistemic Honesty**: Distinguish directly measured empirical data from computational models, surrogates, or analytical estimates.
- **Citation & Attribution**: Attribute all formulas, literature values, and software dependencies to primary sources (e.g., Abbott & von Doenhoff, NACA Report 824, AGARD AR-138).

## 2. Technical Documentation Craft
- Provide concise, actionable summaries at the beginning of reports.
- Include mathematical definitions for all symbols using standard LaTeX notation ($C_L, C_D, C_M, Re, M_\infty$).
- Accompany tabular data with units, experimental bounds, and estimated uncertainties.
- Maintain reproducibility checklists: environment snapshot, dependency versions, random seeds, and input checksums.

## 3. Evaluation & Benchmarking
- Benchmark against standardized reference problems with known analytic or high-order numerical solutions.
- Record both aggregate metrics ($R^2$, RMSE, MAE) and localized extremes (stagnation point $C_p$, suction peak, boundary layer separation location).
- Never report simulated data as experimental measurement.
