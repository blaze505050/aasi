# 03 - Active Learning 2.0 Engine

The Active Learning 2.0 engine in AASI guides high-fidelity simulation acquisition toward flight envelopes where epistemic uncertainty, physical discrepancy, or parameter voids are maximal.

## 1. Modular Acquisition Strategies

The acquisition function evaluates candidate parameter points $\mathbf{x} = (\text{geometry}, M, Re, \alpha)$:

### 1.1 `COST_AWARE` (Default)
Balances information gain against numerical simulation cost:
$$\mathcal{A}_{\text{cost}}(\mathbf{x}) = \frac{w_u \cdot \sigma_u(\mathbf{x}) + w_d \cdot D_{\text{ood}}(\mathbf{x}) + w_p \cdot \Delta_{\text{physics}}(\mathbf{x})}{1 + \gamma \cdot \log_{10}(C_{\text{est}}(\mathbf{x}))}$$

Where:
- $\sigma_u(\mathbf{x})$: Ensemble standard deviation (epistemic uncertainty).
- $D_{\text{ood}}(\mathbf{x})$: Mahalanobis distance from training distribution centroid.
- $\Delta_{\text{physics}}(\mathbf{x})$: Theoretical discrepancy indicator.
- $C_{\text{est}}(\mathbf{x})$: Estimated compute cost (CPU core-hours), proportional to grid cell count $N_{\text{cells}}$ and Reynolds number $Re$.

### 1.2 `UNCERTAINTY`
Focuses purely on maximizing surrogate variance:
$$\mathcal{A}_{\text{unc}}(\mathbf{x}) = \sigma_u(\mathbf{x})$$

### 1.3 `OOD_BOUNDARY`
Targets boundary regions where the surrogate is at the edge of its validated domain:
$$\mathcal{A}_{\text{ood}}(\mathbf{x}) = D_{\text{ood}}(\mathbf{x}) \cdot \left(1 - \exp(-\sigma_u(\mathbf{x}))\right)$$

### 1.4 `SPACE_COVERAGE`
Identifies unpopulated voids in multi-dimensional aerodynamic parameter space using nearest-neighbor Euclidean distance:
$$\mathcal{A}_{\text{space}}(\mathbf{x}) = \min_{\mathbf{x}_k \in \mathcal{D}_{\text{train}}} \|\mathbf{x} - \mathbf{x}_k\|$$

## 2. Candidate Lifecycle State Machine

Each active learning candidate progresses through an auditable state machine:

```
[ PROPOSED ]  ──▶ Generated by ActiveLearningEngine based on acquisition score
      │
      ▼
[  PLANNED ]  ──▶ Converted to formal CFDJobSpec with prescribed mesh & boundary conditions
      │
      ▼
[ EXECUTED ]  ──▶ OpenFOAM / SU2 run executed by user with verifiable logs
      │
      ▼
[ INGESTED ]  ──▶ Passed through CFDQualityControlEngine (ASME V&V 20 checks)
      │
      ▼
[ EVALUATED]  ──▶ Discrepancy computed against prior surrogate predictions
      │
      ▼
[ ARCHIVED ]  ──▶ Permanently committed to versioned training corpus (e.g. V2.0)
```

## 3. 2D Parameter Coverage Canvas

AASI generates 2D projections across any pair of design variables:
- `aoa_vs_mach`
- `mach_vs_re`
- `aoa_vs_re`

The coverage grid discretizes the domain into cells, scoring cell occupancy, density, and identifying un-sampled regions.
