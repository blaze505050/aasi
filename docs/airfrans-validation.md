# AirfRANS Dataset Automated Validation Protocol

**Document ID**: `VAL-AIRFRANS-2022-01`  
**Governing Standard**: AASI Multi-Dataset Scientific Integrity Standard  
**Last Updated**: 2026-09-12  

---

## 1. Overview & Validation Scope

The **AirfRANS** benchmark contains 1,000 OpenFOAM `simpleFoam` simulations across procedurally generated NACA 4-digit and 5-digit airfoils. Before cases or fields are ingested into downstream surrogate models or physics-guided PINN architectures, they must undergo automated validation across four primary axes:

1. **Mesh Sanity & Topology Verification**
2. **Physical Bounds & Fluid Dynamic Feasibility**
3. **Duplicate Case & Parameter Collision Detection**
4. **Cross-Split Geometric Data Leakage Isolation**

---

## 2. Automated Validation Dimensions

### 2.1 Mesh Sanity Verification
Each simulation mesh consists of approximately 190,000 to 230,000 unstructured hybrid cells with wall-normal prism layers.
- **Node Count Positivity**: Verified $N_{\text{nodes}} > 0$.
- **Bounding Box Envelope**: $x \in [-2.0\text{ m}, 5.0\text{ m}]$, $y \in [-3.0\text{ m}, 3.0\text{ m}]$.
- **Wall Distance ($d$)**: Must be strictly non-negative ($d \ge 0.0\text{ m}$), with $d = 0.0$ on the airfoil surface boundary.
- **Surface Normals**: Unit normal vectors must satisfy $\|\mathbf{n}\| = \sqrt{n_x^2 + n_y^2} \approx 1.0 \pm 10^{-3}$ on boundary nodes.

### 2.2 Physical Field & Target Bounds
CFD fields generated by `simpleFoam` under the Spalart-Allmaras turbulence model must satisfy the following physical envelopes:
- **Velocity Fields**:
  - $U_x \in [-20.0, 120.0]\text{ m/s}$ (bounded reverse flow in separation bubbles; peak freestream acceleration $U_{\max} < 1.6 U_\infty$).
  - $U_y \in [-50.0, 50.0]\text{ m/s}$.
- **Kinematic Pressure ($p/\rho$)**: Bounded in $[-5000, 5000]\text{ m}^2/\text{s}^2$.
- **Modified Turbulent Viscosity ($\tilde{\nu}$)**: Strictly non-negative ($\tilde{\nu} \ge 0.0\text{ m}^2/\text{s}$). Values $< 0$ indicate numerical solver divergence and are flagged as `FATAL`.
- **Integrated Forces**:
  - Drag Coefficient: $C_D \ge 0.001$ (strictly positive dissipation; zero or negative drag violates the second law of thermodynamics in steady subsonic flow).
  - Lift Coefficient: $C_L \in [-1.5, 2.5]$ for conventional subsonic NACA sections.

### 2.3 Duplicate Case Detection
Simulations sharing identical conditions within tolerance ($\Delta Re < 10^3$, $\Delta M < 10^{-3}$, $\Delta \alpha < 0.05^\circ$) on identical geometry strings are flagged as redundant duplicates to avoid artificially skewing loss functions or cross-validation statistics.

### 2.4 Cross-Split Geometric Isolation (Zero Leakage)
In standard random cross-validation, a model might train on NACA 0012 at $\alpha = 4^\circ$ and test on NACA 0012 at $\alpha = 6^\circ$. This tests interpolation over $\alpha$, **not** generalization over geometry.
- AASI strictly requires that the geometries in `full_test` have an empty intersection with `full_train`:
  $$\mathcal{G}_{\text{train}} \cap \mathcal{G}_{\text{test}} = \emptyset$$
- Automated hash and string checks enforce zero geometric overlap.

## 3. Severity Taxonomy & Remediation

| Severity | Definition | Action Taken |
|---|---|---|
| `INFO` | Metric within nominal bounds. | Logged in evidence ledger. |
| `WARNING` | Boundary threshold approached (e.g. $C_L > 2.0$, near-stall). | Flagged for physical inspection; case retained. |
| `ERROR` | Physical violation (e.g. $C_D < 0$, $\tilde{\nu} < 0$, unphysical node count). | Case excluded from training/benchmark batches. |
| `FATAL` | Catastrophic schema or mesh corruption. | Dataset adapter execution halted. |

## 4. Execution in AASI

Validation is executed via the `DatasetValidator` engine:
```python
from backend.datasets.catalog import DatasetCatalog
from backend.datasets.validation import DatasetValidator

catalog = DatasetCatalog()
adapter = catalog.get_adapter("DATASET-AIRFRANS-1K")
cases = adapter.list_cases(limit=100)
splits = adapter.get_available_splits()

report = DatasetValidator.run_full_dataset_validation(
    dataset_id=adapter.get_dataset_id(),
    cases=cases,
    splits=splits
)
assert report.is_valid is True
```
All validation outcomes are serialized and signed into the cryptographic research evidence ledger.
